## The problem

This is the Lesson 3 (LCML) original challenge: build a classification
dataset from scratch and train a decision tree on it. The chosen domain is a
recycling sorting-belt sensor that needs to separate paper, plastic, and
metal before disposal, reducing contamination of recyclable batches by mixed
material.

> We train a **multiclass classification** model that takes **four numeric
> sensor readings** (weight, density, electrical conductivity, visual
> opacity) and outputs **the waste's material**: paper, plastic, or metal.

| | |
|---|---|
| **Task type** | Multiclass classification (3 classes) |
| **Input `X`** | Weight (g), density (g/cm³), conductivity (0 to 100), opacity (%) |
| **Output `y`** | One of `papel`, `plastico`, `metal` |
| **Unit of analysis** | One waste item |
| **Metric** | Accuracy on the test set + Gini impurity at the leaf |
| **Worst kind of error** | Predicting metal or plastic as paper (contaminates the recyclable batch) |

## What the app does

**Drag and drop.** Four items (aluminum can, sheet of paper, plastic cup,
used napkin) can be dragged onto the sensor zone, or selected by tap on
touch screens. The classification runs instantly, replicating the same tree
trained in Python: each item's real reading (weight, density, conductivity,
opacity) is compared against the exact thresholds the tree learned.

**Show the reasoning, not just the answer.** After dropping an item, the app
lists every question the tree asked, in the order it asked them, along with
confirmation of whether the prediction matches the item's real material. One
of the four items (the napkin) sits close to the opacity threshold, to show
a boundary case.

**Manual mode.** Below the drag zone, four sliders (one per sensor reading)
let you test any combination of values, with the probability of all three
classes and the full decision path, in the same format as the Lesson 3
project built on the Iris dataset.

**The full tree, on demand.** An expandable section draws the complete tree
(`plot_tree`) and prints the same rules as text (`export_text`).

**Why `max_depth=3`.** Another section reproduces the notebook's
experiment: training the tree at six different depths and comparing train
vs. test accuracy.

## The dataset

`dataset_desafio.csv`: 51 synthetic items (17 per class), generated by a
custom script (`numpy.random.default_rng(42)`), with a normal distribution
per attribute and per class, parameterized with plausible physical ranges
(e.g., metal with much higher conductivity and density than paper or
plastic) and deliberate overlap between paper and plastic, so the tree does
not learn an overly trivial rule.

## The model

**`DecisionTreeClassifier(max_depth=3, random_state=42)`**, trained on 75%
of the 51 items (38 examples), with a stratified split.

### Learned rule

```
conductivity <= 42.30
├── opacity_pct <= 77.65
│   ├── opacity_pct <= 68.35 → plastic
│   └── opacity_pct >  68.35 → paper
└── opacity_pct >  77.65 → paper
conductivity >  42.30 → metal
```

In plain words: high conductivity means metal. Otherwise, low opacity means
plastic; high opacity means paper. Train accuracy: 97.4%. Test accuracy:
92.3% (12 of 13 test examples correct).
